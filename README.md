# Django Polls Project

Simple Django app from tutorial, tweaked with Grenada Food poll and background image of a roti.

## Setup
1. Clone: git clone [your-repo-url]
2. Venv: python -m venv myenv && myenv\Scripts\activate.bat
3. Install: pip install -r requirements.txt
4. Migrate: python manage.py migrate
5. Superuser: python manage.py createsuperuser
6. Run: python manage.py runserver
